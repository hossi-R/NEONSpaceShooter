ENEMIES
宇宙空間には様々な特徴を持つ敵が現れます。

【 BOSS 】
一定時間経過、または特定条件で巨大なボスが出現します。様々な攻撃パターンを持つため、動きを見極めて撃破しましょう！
GAME MODES
[ NORMAL MODE ]
通常のステージ進行です。時間経過でボスが出現します。
・EASY (スコア 0.75倍)
・NORMAL (スコア 1.0倍)
・HARD (スコア 1.5倍)

[ SPECIAL MODE ]
■ EXTRA
難易度最高＆スコア3倍！ただし初期HPが「1」から開始され、回復アイテムも出現しません。

■ ENDLESS
終わりのないサバイバルモード。時間が経つにつれ敵が凶悪になっていきます。

■ BOSSRUSH
ボスとの連戦モード。アイテムが出やすく、初期から自機が強化された状態でスタートします。

■ TIME ATTACK
指定された時間内のスコアを競うモード。敵を連続で倒してCHAIN(コンボ)を繋ぐとスコアが爆発的に伸びます！ダメージを受けるとCHAINはリセットされます。
